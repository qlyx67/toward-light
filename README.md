# 向光而行｜我的求是新程

浙江大学校园摄影展，摄影 / qlyxx。

浏览：https://qlyx67.github.io/toward-light/

九组作品以调整版为默认展示，保留原片对照。五章为「启程、同行、探索、沉淀、创造」，另有四组光影拾遗。支持大图查看、点击放大、原片/调整版切换、并排对照、方向键及触屏左右滑动切换、当前版本下载。

## 文件

- `index.html`：展览结构和创作说明。
- `gallery.css`：桌面、手机、平板布局。
- `gallery.js`：作品渲染、版本切换和大图查看。
- `works.js`：九组作品资料。
- `assets/*-original.webp`：作者上传原片的网页版本。
- `assets/*-v2.webp`：新版调整图预览。
- `assets/*-large.webp`：长边 3840px 的调整图放大版。

纯静态网页，无构建依赖。GitHub Pages 从 `main` 分支根目录发布。本地可运行 `python3 -m http.server 8080` 后访问 `http://localhost:8080`。

## 图片与创作说明

9 张原始摄影素材均由作者拍摄。9 张调整版使用 ChatGPT 生成式编辑，可能改写局部细节；每张保留原片供查看。作者负责原片拍摄、取景构图、主题和选片、照片色调与调整风格，并指导网页整体思路、配色、排版、作品解读及展示与交互细节，逐轮提出修改意见。AI 依据作者要求辅助实现。

上传原片长边 1536px；3840px 下载图为插值放大，**不代表原生 4K/8K 细节**。需要原生高分辨率时，应从相机原始文件重新处理。照片公开展示与下载不等同于授予转载或商业使用许可。
